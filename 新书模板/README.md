# 长篇小说开书模板

这套模板用于新开一本长篇中文网文时快速落地。

## 使用顺序

1. 先填写 `小说框架/00_作品定位.md`
2. 再填写 `小说框架/01_世界观与主线.md`
3. 再填写 `小说框架/02_人物关系表.md`
4. 再填写 `小说框架/06_卷划分.md`
5. 再填写 `小说框架/03_总目录.md`
6. 再补 `小说框架/04_节奏设计.md`
7. 再补 `小说框架/05_作品简介.md`
8. 再补 `小说框架/07_人物小传.md`
9. 正式进入写作前，确认 `项目规则.md`
10. 开始写章后，持续维护 `进度记录.md`
11. 每章完成后，运行 `scripts/run_chapter_acceptance.py`，并维护 `章节验收记录.md`
12. 如需把最新 skills/workflows 一并打包进模板，运行 `scripts/sync_sop_assets.py`

## 当前模板原则

- 新书不机械锁死固定总章数
- 卷划分、章节组块、阶段推进按当次大纲动态整理
- 每章先保证任务、场景、关系、情绪、章尾牵引力成立
- 正文与框架正式交付统一使用真实 `.docx`

## 说明

- 当前目录里的 `.md` 是写作底稿与协作稿。
- 正式交付给 Word 时，按 `小说框架/08_Word排版规范.md` 执行。
- 章节写完后的默认验收命令：

```bash
python3 scripts/run_chapter_acceptance.py --chapter 小说正文/001_章节名.docx
```

- 如果根目录 SOP 更新了，重新同步到模板：

```bash
python3 scripts/sync_sop_assets.py
```
