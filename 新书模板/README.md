# 长篇小说新书模板

这套模板现在只解决两件事：

- 下一本小说可以直接开工
- 长连载时不靠反复喂全量上下文

先读 `下一本小说直用工作流.md`。它是整套模板的总入口。
如果你手里已经有大纲、脑洞或人物想法，先填 `开书输入.md`，再看 `SOP资料/workflows/开书初始化工作流.md`。
如果你当前最关心的是 token 成本，直接看 `SOP资料/workflows/低Token连载工作流模板.md`。
如果你已经安装了 Claude-Mem 和 RTK，再看 `SOP资料/说明文档/Claude-Mem与RTK接入规则.md`。

## 开书顺序

1. 把你的原始大纲、脑洞或想法写进 `开书输入.md`
2. 看 `SOP资料/workflows/开书初始化工作流.md`
3. 用 `SOP资料/说明文档/Codex开书初始化提示模板.md` 让 Codex 完成开书初始化
4. 检查并微调生成好的规划层文件：
   - `小说框架/00_作品定位.md`
   - `小说框架/01_世界观与主线.md`
   - `小说框架/02_人物关系表.md`
   - `小说框架/06_卷划分.md`
   - `小说框架/03_总目录.md`
   - `小说框架/04_节奏设计.md`
   - `小说框架/05_作品简介.md`
   - `小说框架/07_人物小传.md`
5. 确认已经生成：
   - 第一卷执行状态卡
   - 第 1 章任务卡
6. 再确认 `当前有效规则卡.md`

## 连载时默认只读四样

1. `当前有效规则卡.md`
2. 当前卷执行状态卡
3. 当前章任务卡
4. 前 1 章正文；承接复杂时最多前 2 章

不默认回读：

- `进度记录.md`
- `章节验收记录.md`
- `归档/`
- 全量 `小说框架/03_总目录.md`

这些文件只在卡住、误报、追旧线索或改卷节奏时回看。

## 常用命令

先生成本章最小上下文包：

```bash
python3 scripts/prepare_chapter_context.py \
  --volume-card 小说框架/第一卷执行状态卡.md \
  --task-card 小说框架/当前章任务卡.md \
  --output 小说框架/当前章上下文包.md
```

写完章节后做验收：

```bash
python3 scripts/run_chapter_acceptance.py --chapter 小说正文/001_章节名.docx
```

如果手里是源稿 `.txt`，可以一键跑完渲染和验收：

```bash
python3 scripts/run_chapter_pipeline.py --input 小说正文/源稿/001_章节名.txt
```

## 当前模板原则

- 新书不机械锁死固定总章数
- 卷划分、章节组块、阶段推进按当次大纲动态整理
- 原始大纲只在初始化阶段进入默认上下文，初始化完成后退回输入源
- 总目录属于规划层，不进入每章默认上下文
- 日常连载只维护规则卡、状态卡、任务卡和短日志
- 正文与框架正式交付统一使用真实 `.docx`
