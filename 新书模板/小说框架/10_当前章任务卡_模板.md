# 当前章任务卡模板

这张卡只服务当前这一章。

它的作用是把总目录里的大块信息，压成当前一章可以直接执行的最小指令。

## 使用上限

- `本章只办成这 3 件事` 最多 `3` 条
- 其他栏目默认最多 `4` 条
- 单条建议不超过 `80` 字，最长不超过 `120` 字
- 只写命令式任务，不写原因解释，不写整章剧情复述
- 避免连续使用“因为 / 所以 / 意味着 / 体现 / 铺垫”
- 这一章写完后，只保留下一章还真的要继续沿用的内容

## 模板

```md
# 当前章任务卡

## 元信息

- 章节：第 `X` 章 `章名`
- 任务状态：待写 / 修订中 / 已验收
- 来源：总目录第 `X` 章条目 + 当前卷状态卡
- 默认回读：第 `X-1` 章正文

## 本章只办成

- 完成……
- 暴露……
- 推进……

## 必须承接

- 承接第X章结尾：……
- 接住某个关系 / 物件 / 压力：……

## 本章禁写

- 不提前写……
- 不重复写……

## 章尾结果

- 章尾落到……

## 建议技能

- 主：正文语言风格
- 辅：场景描写

## 写完后回填

- 状态卡里要更新哪几条
- `进度记录.md` 记哪条短记录
- `章节验收记录.md` 关注什么风险
```

## 使用说明

- 新建一章前，先从总目录里抽出这一章真正要办成的事，写成任务卡。
- 进入正文后，日常默认读任务卡，不回读全量总目录。
- 如果任务卡已经写到需要长篇解释，说明这章拆得还不够清，或者状态卡没有压干净。
