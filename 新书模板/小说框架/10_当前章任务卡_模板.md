# 当前章任务卡模板

这张卡只服务当前这一章。

它的作用是把总目录里的大块信息，压成当前一章可以直接执行的最小指令。

## 使用上限

- `本章只办成这 3 件事` 最多 `3` 条
- 其他栏目默认最多 `4` 条
- 不写长段解释，不写整章剧情复述
- 这一章写完后，只保留下一章还真的要继续沿用的内容

## 模板

```md
# 当前章任务卡

## 元信息

- 章节：第 `X` 章 `章名`
- 任务状态：待写 / 修订中 / 已验收
- 来源：总目录第 `X` 章条目 + 当前卷状态卡
- 默认回读：第 `X-1` 章正文

## 本章只办成这 3 件事

- 本章结果 1
- 本章结果 2
- 本章结果 3

## 本章必须承接

- 上一章留下的哪个结果必须接住。
- 哪个关系、物件、压力不能断。

## 本章不能写

- 哪条线现在还不能提前开。
- 哪种重复回写必须避免。

## 建议调用

- 主调用：哪个 workflow / skill
- 次调用：哪个 workflow / skill

## 本章完成判定

- 这一章写完后，必须落地的结果是什么。
- 如果没出现这些结果，就不算真正完成。

## 写完后回填

- 状态卡里要更新哪几条
- `进度记录.md` 记哪条短记录
- `章节验收记录.md` 关注什么风险
```

## 使用说明

- 新建一章前，先从总目录里抽出这一章真正要办成的事，写成任务卡。
- 进入正文后，日常默认读任务卡，不回读全量总目录。
- 如果任务卡已经写到需要长篇解释，说明这章拆得还不够清，或者状态卡没有压干净。
