# Codex 开书初始化提示模板

这份模板给你做一件事：

- 把 `开书输入.md` 直接交给 Codex，生成新书初始化资料

## 一、有现成大纲时

把下面这段直接发给 Codex：

```text
请基于 `开书输入.md` 完成这本新书的初始化。

只读取这些文件：
1. 开书输入.md
2. 项目规则.md
3. 当前有效规则卡.md
4. SOP资料/workflows/开书初始化工作流.md
5. 小说框架/09_当前卷执行状态卡_模板.md
6. 小说框架/10_当前章任务卡_模板.md

任务：
1. 判断开书输入是否足够完成初始化
2. 如果缺信息，只列最少必要补充项，不要长问卷
3. 把输入归一化到规划层文件
4. 生成第一卷执行状态卡
5. 生成第1章任务卡
6. 告诉我写第1章时，默认只需要读取哪些文件

要求：
- 不要长篇复述我的输入
- 不要机械锁死总章数
- 总目录按卷和阶段整理，不写成每章流水账
- 没想清的地方允许标 [待定]
- 初始化完成后，不再把开书输入当成日常连载上下文
```

## 二、只有粗脑洞时

把下面这段直接发给 Codex：

```text
请基于 `开书输入.md` 帮我完成新书初始化。

只读取这些文件：
1. 开书输入.md
2. 项目规则.md
3. 当前有效规则卡.md
4. SOP资料/workflows/开书初始化工作流.md
5. 小说框架/09_当前卷执行状态卡_模板.md
6. 小说框架/10_当前章任务卡_模板.md

任务：
1. 先判断现在的信息能不能初始化
2. 如果不能，只补问最少必要信息，最多 5 项
3. 如果能，就直接生成规划层文件
4. 生成第一卷执行状态卡
5. 生成第1章任务卡
6. 最后给出进入第1章连载时的最小读取清单

要求：
- 不要为了补完整而乱编细设定
- 不要长篇解释理论
- 先保证项目能开工，再追求细化
- 初始化完成后，默认以项目文件为准，不再反复回读原始脑洞
```

## 三、初始化后写第 1 章

初始化完成后，提示词切到这一版：

```text
请只基于以下文件工作：
1. 当前有效规则卡.md
2. 当前卷执行状态卡.md
3. 当前章任务卡.md
4. 当前章上下文包.md
5. 前1章正文（如果还没有，就不要自行补读其他材料）

任务：
写第1章初稿 / 修订第1章。

要求：
- 不回读开书输入.md
- 不回读总目录，除非我明确要求
- 本章只完成任务卡里的结果
- 写完后说明状态卡和任务卡该怎么回填
```
