# 场景描写

把场景写成会对人物施加影响的环境，不要写成静止布景。

## 核心目标

场景描写至少承担一项作用：
- 传达情绪
- 传达贫富与处境
- 传达权力关系
- 制造压迫或安稳感
- 推动行动选择
- 提供可记忆的画面

## 基本原则

- 不写“全景汇报”，只写有用细节。
- 优先选择能承担双重以上功能的细节。
- 场景必须和人物身体接触，不能悬空。
- 环境描写要影响人物下一步，而不是停留在装饰层。

## 场景写法SOP

1. 先确定本场景的主压力。
2. 只挑2到4个关键细节。
3. 让人物与场景发生物理接触。
4. 用场景逼出下一步。

## 本skill的SOP流程

1. 先判断这一场景最重要的功能：压迫、安稳、暴露、过渡、生产或关系升温。
2. 删去无功能的背景板细节。
3. 保留2到4个能同时承担画面和叙事功能的细节。
4. 让人物碰到场景，而不是站在场景外介绍场景。
5. 确认场景描写结束后，人物的下一步选择变得更自然。
6. 再检查这一场景是否留下至少一个可记忆画面。

## 正反例

### 反例：清单式描写
这间屋子有一张床，一张桌子，一个柜子，一扇窗户，窗户边还有一个盆，地上有很多灰，看起来很破。

### 修正示例
窗纸破了大半，风从缝里直往里钻。床脚一高一低，桌上落着一层灰，手指一抹便见底色。沈春禾试着把门推严，门板却还是晃了两下——这屋子今晚若不先堵风，谁都睡不踏实。

### 反例：只有好看，没有作用
院子很安静，月光很美，树影也很好看，空气很清新，让人觉得景色宜人。

### 修正示例
院里静得过分，连风过树梢的声音都听得见。月光把地上的裂缝照得发白，空荡荡的，没有半点人气。她在门口站了一会儿，才意识到这里太久没人住了，今夜连烧水都得先找柴。

## 高效结构模板

1. 一个视觉锚点
2. 一个声音或触感细节
3. 一个人物与环境的动作
4. 一个由此带出的判断或压力

## 修订流程

写完场景后检查：
- 这几个细节是不是都在做事？
- 场景是否改变了人物的状态或选择？
- 能否一眼分辨这是哪个世界、哪个阶层、哪个时刻？
- 读者能否记住其中一个具体画面？

## 输出要求

最终场景应当有用、有身体感、有情绪重量、有辨识度。不是“写得很满”，而是“写得很准”。
