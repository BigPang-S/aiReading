# 章节验收与连续性校验

这个 skill 是辅助验收层，不替代现有 6 个基础写作 skill。

它的职责不是直接写正文，而是判断：
- 这一章能不能交付
- 这一章是否符合当前项目规则
- 这一章是否真的把故事往前推了一步
- 这一章是否开始出现回退、复读、串线和整体混乱

## 核心目标

每章完成后，给出一份可执行的验收结论：
- `通过`：可继续进入下一章
- `警告`：可以进入下一章，但必须记住风险点
- `不通过`：必须先修，再继续连载

## 验收分层

### 第一层：硬规则校验

必须检查：
- 标题格式是否为 `第X章 XXXXX`
- 正文字数是否符合当前规则
- 是否存在重复段落、重复表意、同义反复硬拉长度
- 是否存在乱码、广告、外链、异常 HTML 痕迹
- 是否存在明显超长段落
- 是否存在文本内显式事实矛盾，例如“这四个字”与前文引语实际字数不符
- 是否存在显式数量指代不一致，例如前文写“两名女官”，后文近距离却写成“那三名女官”
- 是否存在显式时间顺序回退，例如已经推进到“次日”，后文无回忆提示却又写回“当晚”
- 是否存在高风险称谓组冲突，例如同一人物在近距离文本里被写成明显互斥的身份称谓
- 是否存在显式物件状态冲突，例如前文刚写“把刀放回托盘”，后文无拿回动作却又写“仍按着腰间刀柄”
- 是否存在高风险身份设定冲突，例如同一人物近距离被写成“女官”又写成“内侍”
- 是否存在显式场景位置跳变，例如前文还在“偏殿中”，后文无移动提示却直接写回“宫门外”
- 是否存在显式人物伤势连续性冲突，例如前文刚写“左臂缠着纱布”，后文无养伤过渡却写“左臂完好无损”
- 是否存在显式钱粮库存连续性冲突，例如前文写“只剩三十两银子”，后文无进出账动作却写“账上还有五十两银子”
- 是否存在显式出场人物在场性冲突，例如前文刚写“屋里只剩裴照雪一人”，后文无进门动作却让柳十一接话
- 是否存在高风险对话归属错位，例如连续多段纯对白都没有说话人归属，或同一段引语附近同时挂了多个说话人标签
- 是否存在高风险角色口吻突变，例如同一角色近距离上一句还在用“臣 / 末将 / 卑职”体系，下一句又突然跳成“老娘 / 滚蛋 / 得了吧”体系
- 是否存在已解决任务被重复当首难题重写，例如前文刚写“粮食已经有着落”，后文无新变故却又写成“眼下最难的还是缺粮”
- 是否存在高风险对话动作链断裂，例如前文刚写“某人没有接话 / 一言不发”，后文无任何停顿或转折提示却又立刻让他开口
- 是否存在高风险视角越界，例如相邻近距离段落连续进入两个不同人物的明确内心活动，且没有视角切换提示
- 是否存在高风险关系温度回退，例如前文已明确写到“终于肯信 / 不再防着 / 声音放软”，后文无新变故却又写回“还是不信 / 仍防着 / 生分”
- 是否存在高风险事件因果断裂，例如前文刚写“城门还没开 / 旨意还没下 / 人还没到”，后文无补台阶却直接写成完成态
- 是否存在高风险世界观常量自撞，例如同一势力、编制、州郡数量、营卫人数被前后写成两个口径
- 是否存在高风险大纲节点偷跑，例如当前章正文直接命中后续章节的独特事件短语
- 是否存在高风险身份权限边界自撞，例如前文刚写“某人无权调兵 / 无权入殿”，后文无获准提示却又直接执行该权限动作
- 是否存在高风险伏笔回收缺口，例如前几章明确埋下“信 / 名册 / 婚书 / 旧案”类伏笔，到当前阶段仍完全没有回收动作
- 是否存在高风险阶段目标空转，例如同一阶段目标连续数章反复被当作“眼下最要紧的事”，但没有明确推进完成
- 是否存在高风险角色资源消耗失闭环，例如前文刚写“手里只剩一包药”，后文无补给却又连续递出两包药
- 是否存在高风险承诺兑现超时，例如前几章明确承诺“明日给答复 / 三日内送来名册”，到当前阶段仍未见兑现
- 是否存在高风险多线并行优先级错乱，例如前文刚把 A 线定成“先办”，后面几章却连续改去处理 B 线、C 线，A 线没有推进
- 是否存在高风险角色立场反复横跳，例如前文刚明确“站到裴照雪这边”，后文无变故说明却又写成“站到魏崇礼那边”
- 是否存在高风险信息揭示密度失衡，例如同一小段或同一小窗里连续堆出多个“原来 / 其实 / 真相是 / 这才知道”
- 是否存在高风险章尾钩子失效，例如章尾收在“众人散去、谁也没再说话”这类平尾句上，却没有下一步牵引
- 是否存在高风险情绪反应延迟或缺席，例如前文刚发生强冲击事件，后面近距离段落却没有任何情绪、动作或判断承接
- 是否存在高风险关键决策缺代价，例如人物明确“决定去做”，但正文没有交代成本、风险、交换或放弃了什么
- 是否存在高风险支线抢主线，例如当前章大量重复支线任务、关系线或旧谜团，却挤掉本章应有的主线推进

### 第二层：本章成立性校验

必须回答：
- 这章有没有明确任务
- 这章有没有场景承载
- 这章有没有结果，而不是只搬信息
- 这章有没有人物关系或主线状态变化
- 章尾有没有继续阅读牵引力

### 第三层：大纲推进校验

必须判断：
- 这章是否对应当前目录 / 大纲里应做的那一步
- 是否真的把主线、支线、关系线向前推了
- 是否偷跑了后面才该发生的内容
- 是否把已经完成的节点又重新写一遍

### 第四层：连载连续性校验

必须检查：
- 时间线有没有倒退或跳乱
- 人物关系温度是否连续
- 人物立场、口气、动作习惯是否突然变形
- 经营 / 生计 / 任务状态是否与前文一致
- 是否把前 1 到 3 章已经说明过的信息大量复述
- 是否因为补字导致“看起来热闹，实则不前进”
- 对话是否因为省略说话人过多而开始错位
- 同一角色的说话风格是否突然从一种稳定体系跳到另一种稳定体系
- 已经解决的难题是否被无因重置成“眼下第一难题”
- 对话动作是否自撞，例如刚写“没接话”，下一拍就无过渡开口
- 主视角是否在近距离段落里乱跳进多个角色脑内
- 关系线是否刚推进就被无因写回原地
- 事件是否在前置条件未满足时突然完成
- 世界观里的稳定口径是否前后自撞
- 当前章是否直接偷跑到后面几章才该发生的明确节点
- 身份和权限边界是否被无因越过
- 前几章强信号伏笔是否拖得过久却完全不回收
- 阶段性目标是否连续多章只提不动
- 角色手里的有限资源是否被写成“越花越有”
- 前几章立下的明确承诺是否拖过阶段仍不兑现
- 多条主线并行时，优先级是否反复乱跳
- 角色立场是否在没有足够代价和转折的情况下来回跳
- 信息揭示是否集中爆出，导致读者来不及消化
- 章尾是否只是收住了句子，却没挂住读者
- 强冲击事件后，人物是否像没事一样直接跳过去
- 关键决策后，文本是否忘了交代代价和后果
- 支线内容是否开始挤占本章主线功能

## 默认执行流程

### 1. 先读当前有效规则

优先读取：
- `项目规则.md`
- `小说框架/03_总目录.*`
- `小说框架/06_卷划分.*`
- `进度记录.md`

如果当前项目没有这些文件，至少要拿到：
- 当前章节
- 当前阶段大纲
- 前 1 到 3 章正文

### 2. 先跑脚本做硬规则体检

如果当前章节已经落地为文件，优先运行：

```bash
python3 skills/novel-chapter-acceptance/scripts/chapter_guard.py \
  --chapter 路径/到/当前章节.docx \
  --rules 路径/到/项目规则.md \
  --outline 路径/到/小说框架/03_总目录.md \
  --previous-dir 路径/到/小说正文
```

脚本负责给出：
- 标题格式
- 正文字数
- 章节编号连续性
- 当前章内重复段落
- 与前文章节的高相似重复
- 上一章尾段与本章开头的复述重叠
- 大纲中是否能找到当前章节条目

如果没有文件，跳过脚本，直接做人工语义验收。

### 3. 再做语义验收

拿到脚本结果后，再人工补完下面四个判断：

1. **这章推进了什么**
2. **这章对应大纲的哪一步**
3. **这章是否把上一阶段已经成立的结果写回去了**
4. **这章是否因为补字让重复信息变多，但有效推进没变多**

### 4. 最后给出交付结论

输出时固定分成三档：
- `阻塞问题`
- `风险警告`
- `通过结论`

如果存在阻塞问题，不要把这章当成已验收通过。

## 大纲推进检查问题单

验收时必须逐条过：

1. 当前章节在总目录里本来应该完成什么？
2. 本章结尾时，人物处境是否比开头更靠近下一节点？
3. 本章是否只是把上一章的结论换个场景再说一遍？
4. 本章新增的信息、关系变化、经营变化、决定变化分别是什么？
5. 如果删掉这章，后文会不会少掉一个必要台阶？
6. 如果删不掉，说明这章有推进；如果删掉也不影响，说明这章大概率发空。

## 连续性检查问题单

重点盯下面几类容易写乱的点：

- 时间：今天、次日、隔天、季节、阶段是否对得上
- 地点：人物上一章在哪里，这章为什么能到这里
- 物件：钱、货、伤、药、书信、工具、铺子、田地等状态是否连续
- 关系：上一章刚冷下去，这章不能无因变热；上一章刚立边界，这章不能无因退回去
- 情绪：人物不能每章都重新震惊、重新难过、重新下决心
- 经营：已解决的问题不能反复当“第一次难题”重写

## 常见不通过情形

### 1. 章节像在原地踏步

表现：
- 写了很多动作和对话，但结局状态没变
- 章尾没有新门口，只是把本章内容再总结一遍

修法：
- 补一个明确结果
- 补一个下一步成本、风险或新机会

### 2. 章节把前文又写一遍

表现：
- 上一章刚讲过的处境，这章开头又大段复述
- 人物又重新想了一遍读者已经知道的事

修法：
- 删复述
- 只保留最短承接
- 把篇幅换成新动作、新判断、新后果

### 3. 文本内显式事实矛盾

表现：
- 写“这四个字”“这两个字”，但前文引语实际不是这个字数
- 明写“只剩一人 / 两封信 / 三日后”，与同章已给出的硬信息对不上

修法：
- 这类问题优先视为硬伤
- 先改正显式事实，再谈文风和润色
- 能做成规则的，优先补进自动验收脚本

### 4. 数量 / 时间 / 称谓显式冲突

表现：
- 前文写“两名女官”，后文近距离却写成“那三名女官”
- 已经写到“次日”，后文无回忆提示却又直接回到“当晚”
- 同一人物在相近段落里被写成明显不相容的称谓组

修法：
- 数量冲突优先按硬伤处理
- 时间和称谓先当高优先级警告，人工复核是否真是回忆、讽称或视角差异
- 如果人工确认确属错误，再补进更严格的自动规则

### 5. 物件 / 身份 / 场景显式冲突

表现：
- 前文刚写“把名册放回案上”，后文无重新拿起动作却又写“她把名册抱在怀里”
- 同一人物近距离被写成“女官”又写成“内侍”
- 前文还在“偏殿中”，后文无移动提示却直接写回“宫门外”

修法：
- 物件和场景先按高优先级警告处理，人工确认是否漏写了过渡动作
- 身份设定只拦截互斥程度高的词组，避免误伤人物多重身份
- 如果确认是硬伤，优先补动作、补转场或统一设定，而不是只改一句表面文案

### 6. 伤势 / 库存 / 在场性显式冲突

表现：
- 前文刚写“左臂缠着纱布”，后文无时间跳转和养伤提示，却又写“左臂完好无损”
- 前文写“只剩三十两银子”，后文无买卖、进账、分账提示，却又写“账上还有五十两银子”
- 前文刚写“屋里只剩裴照雪一人”，后文无进门动作，却让另一名角色立刻说话或做动作

修法：
- 这三类先按高优先级警告处理，只抓显式强信号
- 伤势和库存优先补“恢复 / 进出账”的台阶说明
- 在场性问题优先补“退场 / 入场 / 转场”动作，避免角色像瞬移

### 7. 章节推进和大纲错位

表现：
- 该发生在后面的节点提前发生
- 当前章标题和实际内容不一致
- 大纲写的是“立规矩”，正文大半却在重复“为什么要立规矩”

修法：
- 先对齐本章功能
- 再删掉跑偏内容

### 8. 对话 / 口吻 / 难题状态失控

表现：
- 连续多段对白都没有说话人归属，读者开始分不清是谁在说
- 同一角色近距离一会儿是稳定的官场 / 军中口吻，一会儿又突然切成完全不同的市井粗口体系
- 前文已经写明“问题解决了 / 有着落了 / 稳住了”，后文无新损失、无新变故，却又把同一问题写回“眼下第一难题”

修法：
- 对话问题优先补最短归属，不要让对白裸奔太久
- 口吻问题先确认角色有没有“故意讥讽 / 失态 / 模仿”的剧情理由，没有就统一回角色稳定声线
- 难题状态问题优先补“新变故”或删掉重复立题句，避免经营线反复归零

### 9. 对话动作 / 视角 / 关系回退失控

表现：
- 前文刚写角色沉默、不答、不接话，后文无停顿和转折却立刻开口
- 相邻段落连续进入两个不同角色的明确内心活动，看起来像镜头乱跳
- 前文刚写到“终于肯信 / 不再防着 / 声音放软”，后文无误会、争执、背叛等新变故，却又写回“还是不信 / 仍防着 / 生分”

修法：
- 对话动作问题优先补“片刻后 / 良久 / 终于 / 静了静”等最短过渡
- 视角问题优先守住单段或近距离单主视角，必要时明确写出切镜头提示
- 关系回退问题先补新矛盾、新误会或新代价；没有新事件就不要把关系线写回起点

### 10. 因果 / 常量 / 大纲节点失控

表现：
- 前文刚写“门还没开 / 旨意还没下 / 人还没到”，后文无过渡就直接写成“门开了 / 旨意下了 / 人到了”
- 同一世界观常量前后口径打架，例如“凤翎营共有四百人”后又无扩编裁撤写成“三百人”
- 当前章正文直接出现本该属于后续章节的明确事件短语

修法：
- 因果问题优先补最短前置台阶或时间台阶，不要让结果裸跳出来
- 常量问题先统一世界观口径；如果设定真的变化了，就补“扩编 / 裁撤 / 折损 / 并入”等原因
- 偷跑问题优先把事件拆回当前章该有的铺垫层，保留预兆，不要提前交付结果

### 11. 权限 / 伏笔 / 阶段目标失控

表现：
- 前文刚写“无权调兵 / 无权入殿 / 无权查卷宗”，后文无奉旨、得令、获准提示却又直接做成了
- 前几章明确埋下“信 / 名册 / 婚书 / 旧案 / 身份 / 来路”等伏笔，到当前章仍没有任何查问、翻找、对质、揭开动作
- 同一目标连续数章都在说“眼下最要紧的是……”，但始终没有明确完成、办妥、立住、保住

修法：
- 权限问题优先补授权台阶；如果就是越权，要把越权成本写出来，而不是让它像默认可做
- 伏笔问题优先补最短回收动作，不一定一次解开，但至少要重新触发一次
- 阶段目标空转时，先删重复立题句，再补真实进展、代价或失败结果

### 12. 资源 / 承诺 / 并行优先级失控

表现：
- 前文刚写“只剩一包药 / 只剩一两银子”，后文无补给却又连续支出超过库存
- 前几章明确承诺“明日给答复 / 三日内交名册 / 回京后给交代”，到当前章仍没有兑现动作
- 前文刚把某条线定成“先办”，后面几章却不断切去别的线，原优先线完全没推进

修法：
- 资源问题优先补来源、补补给，或者删掉多余支出动作
- 承诺问题优先补兑现动作；如果暂时做不到，就明确写出失约代价和原因
- 优先级问题先确认有没有真正的突发变故；没有的话，不要每章都重置“当前头号任务”

### 13. 立场 / 信息揭示 / 章尾钩子失控

表现：
- 前文刚明确某角色“站到谁那边 / 替谁说话 / 帮着谁”，后文无变故、无做戏、无试探说明，却又突然站到另一边
- 同一小段或三段小窗里连续堆出多个“原来 / 其实 / 真相是 / 这才知道”，信息一下子爆太多
- 章尾收在“众人散去 / 谁也没再说话 / 夜色渐深”这类平尾句上，却没有问题、代价、命令、来人、下一步

修法：
- 立场问题先补立场改变的代价、原因或伪装说明；没有这些，就不要让角色横跳
- 揭示密度过高时，先拆成前因、揭示、后果三步，不要把多个关键答案挤在一小窗里
- 章尾问题优先补一个最短钩子，不一定大爆点，但至少给读者一个“接下来会怎样”

### 14. 情绪 / 决策 / 主支线比例失控

表现：
- 前文刚出强冲击事件，后面近距离段落却没有任何愣住、沉默、发紧、失措、追问或判断
- 人物刚做出关键决定，正文却没有交代代价、风险、交换条件或因此放弃了什么
- 本章大量篇幅都在支线事务、旧谜团或关系拉扯上，真正该推进的主线动作很薄

修法：
- 情绪问题优先补一个最短反应台阶，不一定长，但不能像事件没发生
- 决策问题优先补代价，不补代价的决定会显轻飘
- 支线抢主线时，先把本章主线结果补足，再决定支线还能占多少篇幅

当前自动规则默认只抓强信号：
- 情绪反应优先检查强冲击事件后的近距离承接，避免把普通气氛描写误判成“无反应”
- 决策代价优先检查关键决定后一小窗内是否出现风险、交换、放弃项或成本说明
- 支线抢主线优先按“当前章正文明显漂向邻章大纲功能”来提醒，不先用宽泛词频乱抓

### 15. 补字后整体更乱

表现：
- 字数上去了，但重复句和回顾句显著变多
- 新增内容没有引起关系、主线或结果变化

修法：
- 先删重复
- 再补有效推进
- 验收标准看“状态变化”，不看“新增字数”

## 输出要求

验收结论必须包含：
- 当前章节结论：通过 / 警告 / 不通过
- 当前章节匹配的大纲条目
- 这章推进了什么
- 发现了哪些回退 / 重复 / 串线风险
- 如果不通过，必须指出先修哪几处

## 备注

这个 skill 最适合在以下时机调用：
- 每章初稿写完后
- 每章修订完成后
- 批量补字完成后
- 准备进入下一章前

如果任务是长期连载，默认把这个 skill 作为每章结束后的固定验收步骤。
