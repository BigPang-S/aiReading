# 去AI味修订

这个 skill 只做一件事：
把“已经像样的生成句子”改回“像人写、像小说正在发生”的句子。

## 什么时候用

- 章节结构已经基本成立，但读起来有生成味
- 句子过工整，像在替读者提炼主题
- 旁白老替人物下判断
- 情绪、关系、成长都被作者直接说穿
- 同一章里“她知道 / 他明白 / 原来 / 这一刻 / 不再只是 / 说到底”明显偏多

## 不适用

- 章心没立，剧情没有结果
- 人物位置乱了，承接点没对上
- 只是想把文字“修得更华丽”

遇到这些情况，先回 `正文语言风格` 或总控 skill，不要先做去 AI 味。

## 核心判断

AI 味通常不在词本身，而在写法：

- 先给结论，再补场面
- 先下主题，再让人物动
- 句子太整齐，节奏太平均
- 情绪全被解释完，读者没有参与感
- 关系变化都被作者替人物说穿
- 所有人都“很会表达”，很少有人说半句、忍半句、做岔半步

## 执行流程

1. 先圈句，不先通篇抛光。优先圈段尾、转折句、情绪总结句。
2. 判断它属于哪类 AI 味。需要时读 `references/常见AI味模式.md`。
3. 每句改写只做四件事：
   - 删判断壳
   - 落具体人事
   - 打散工整句势
   - 把意义留给后果，不留给旁白
4. 一段最多重写 1 到 2 处最重的句子，不要整段都“修漂亮”。
5. 收尾时再看：删掉抽象判断后，是不是更像小说正在发生。

## 高风险模式

### 1. 先否后明句

高风险样子：
- `不是……而是……`
- `不再……而是……`
- `不是……却是……`

改法：
- 拆成前后两个动作或两个结果
- 不要一句把意义说圆

### 2. 主题提炼句

高风险样子：
- `原来……`
- `说到底……`
- `这一刻……`
- `这不只是……更是……`

改法：
- 先判断是不是非说不可
- 能删就删
- 真要保留，尽量改成人物自己的短判断，不要用作者口气盖章

### 3. 万能心理说明句

高风险样子：
- `她知道`
- `他明白`
- `她忽然意识到`
- `她心里一紧 / 一酸 / 一沉`

改法：
- 优先改成动作、停顿、递还、收回、没接话、改口、换手、转身
- 情绪尽量落在呼吸、手上、眼神、物件处理方式

### 4. 抽象群像句

高风险样子：
- `所有人都……`
- `黑石堡第一次……`
- `她们终于……`

改法：
- 优先落到两三个人
- 或者落到一个具体变化：哪块板立起来、哪条路能走、哪口锅怎么分

### 5. 句子太整齐

高风险样子：
- 连续三句以上长度接近、结构相同、意义递进得太工整
- 段尾总想压一句“像结论”的话

改法：
- 删掉最像海报的一句
- 把其中一句改成动作句或短对话
- 不要每段都留“漂亮收束”

## 修订原则

- 宁可短一点，不要解释圆满
- 宁可留半口气，不要一次讲透
- 宁可具体一人一物，不要抽象概括一群人
- 宁可有点毛边，不要句句像海报文案
- 不要只做同义词替换，那去不掉 AI 味

## 终检五问

1. 这句话是谁会说、会想、会做？如果只像作者会说，重写。
2. 删掉抽象判断后，读者还能看懂吗？能，就删。
3. 这句是不是想得太明白、说得太完整？是，就留点空。
4. 这段是不是每句都同样整齐？是，就打断节奏。
5. 这章是不是只剩“好看句子”，没有“活人动作”？若是，回补动作和后果。

## 搭配建议

- 章心没稳：先用 `正文语言风格`
- 情绪是假：搭 `情绪动作表达`
- 对话太会说：搭 `人物关系对话` 或 `人物专属台词签名`
- 全章终轮：最后再走 `章节验收与连续性校验`

## 输出要求

目标不是“修得更像文学评论”，而是“修得更像正在发生的小说正文”。
