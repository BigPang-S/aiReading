# 章节创作工作流模板

这份模板用于“从零开始写一章”，适合中文网文与长篇小说连载创作。

目标不是把一章写得很满，而是把一章写得：
- 不能为了凑字数而凑字数
- 不能通过重复段落、重复表意、同义反复硬拉字数
- 有明确任务
- 有场景承载
- 有人物区分
- 有情绪落点
- 有章尾牵引力

可配合以下 skill 使用：
- 正文交付要求：小说正文默认输出为 **Word 文档**，优先使用 `.docx`。禁止使用 HTML 伪装 `.doc` 作为正式交付。

- 小说写作总控skill
- 去AI味修订
- 正文语言风格
- 场景描写
- 情绪动作表达
- 人物专属动作签名
- 人物专属台词签名
- 人物关系对话

## 一、创作前先定四件事

写一章前，先回答：

1. **这章要完成什么任务？**
   例如：分家、进山、交易、冲突、告白、试探、反转、收获。

2. **这章的核心场景是什么？**
   例如：堂屋、破屋、集市、山路、灶房、雨夜、铺子。

3. **这章最重要的人物关系是谁和谁？**
   例如：主角与母亲、主角与男主、主角与反派。

4. **这章结束时要留下什么？**
   例如：决定、隐忧、新机会、关系变化、下一步行动。

如果这四件事说不清，先不要急着写正文。

---

## 二、章节创作五步法

### 第一步：定章目标

一句话写清这章的功能。

示例：
- 这一章要写主角被分家后第一次在破屋里立住心。
- 这一章要写男女主第一次形成合作关系。
- 这一章要写主角第一次靠手艺赚到钱。

### 第二步：定场景压力

不要先想“我要写多少事”，先想“这一章最有感觉的空间是什么”。

然后确定这个空间带来的主压力：
- 冷
- 穷
- 挤
- 乱
- 湿
- 曝露
- 热闹
- 压迫
- 安稳

### 第三步：定人物与关系

确定：
- 谁是这章主视角重心
- 谁负责制造冲突
- 谁负责承接情绪
- 谁负责改变关系温度

### 第四步：定这一章的情绪线

一章最好有简单清楚的情绪变化。

常见结构：
- 压 -> 稳
- 紧 -> 松
- 冷 -> 暖
- 防 -> 信
- 忍 -> 反击
- 平 -> 起波澜

### 第五步：定章尾钩子

章尾至少留下一个：
- 新问题
- 新机会
- 新关系变化
- 新决定
- 新危险

## 三、最稳的章节结构模板

### 模板A：常规推进章
1. 开章画面 / 承接点
2. 当前问题出现
3. 人物应对
4. 过程中的小波折
5. 落到结果
6. 章尾留下下一步

### 模板B：情绪关系章
1. 一个带氛围的相处场景
2. 两人或多人围绕实事说话
3. 潜台词逐渐浮出来
4. 一个动作或一句话改变温度
5. 不说透，但关系推进
6. 章尾留余味

### 模板C：冲突章
1. 快速进入矛盾
2. 双方立场清楚
3. 冲突升级
4. 主角或关键人物出手
5. 局面暂时落定
6. 章尾埋后效

## 四、正文落笔顺序建议

真正开始写时，建议按这个顺序想：

1. **先写开头画面**
2. **再写这一章的问题**
3. **再写人物的动作和对话**
4. **最后补必要场景细节**
5. **写完后回头修语言统一性**

不要一开始就试图把环境、心理、关系、金句全一次写满。

草稿出来后，如果明显出现：
- 开头概括
- 过渡句太顺
- 心理句太满
- 对话太会说
- 段尾总想收主题

不要直接抛光，先接：
- `SOP资料/skills/去AI味修订/SKILL.md`
- `SOP资料/workflows/去AI味修订工作流模板.md`

## 五、不同章节类型的创作重点

### 1. 开篇章
重点：
- 冲突快
- 主角立住
- 信息别太散
- 章尾要抓人

### 2. 过渡章
重点：
- 即使过渡，也要有小结果
- 不能只负责搬信息
- 要埋下一步的动势

### 3. 感情章
重点：
- 关系变化比甜言蜜语更重要
- 先有相处与分担，再有心动感
- 场景和动作比直白说明更重要

### 4. 做事章 / 经营章
重点：
- 避免写成操作说明
- 一边做事，一边带人物和关系
- 要让收获或风险具体可感

### 5. 高冲突章
重点：
- 节奏收紧
- 台词要更准
- 场面不要写乱
- 冲突后要有余波

## 六、创作时最常见的问题

### 问题1：写着写着像流水账
修法：
- 回看这章目标是否清楚
- 压缩过渡句
- 增加场景与动作承载
- 删除重复解释

### 问题2：这一章不知道写什么
修法：
- 先定这章结果
- 再倒推人物必须经历什么
- 让场景帮助制造问题

### 问题3：一写对话就发平
修法：
- 先想关系，而不是先想台词
- 同一句话换对象换说法
- 用动作和停顿补足潜台词

### 问题4：章尾总收不住
修法：
- 章尾不要总结整章意义
- 直接收在“下一步的门口”

## 七、创作后快速自检

写完一章后问自己：

1. 这章一句话能不能说清写了什么？
2. 这章最重要的场景画面是什么？
3. 这章谁和谁的关系发生了变化？
4. 这章有没有至少一个情绪点是靠动作落地的？
5. 这章结尾能不能让人想看下一章？

如果这五条里有两条答不上来，这章还需要回修。

## 八、推荐调用顺序速查版

### 从零写一章
1. 小说写作总控skill
2. 正文语言风格
3. 场景描写

## 九、一句话版创作原则

> 先知道这章要把人带到哪儿，再决定怎么写这一路。

## 十、正文硬性格式与内容要求

### 章节标题格式
统一使用：`第X章 XXXXX`

### 每章字数
- 每章目标 3200—3800 字
- 任何一章最低不低于 3200 字

### 排版要求
- 正式交付统一使用真实 `.docx` Word 文档
- 章节标题单独成行，统一为：`第X章 XXXXX`
- 章节标题使用黑体三号，居中排版
- 正文使用宋体小四，首行缩进 2 字符
- 行距固定 29 磅（可接受 28—30 磅的接近值）
- 段前 0 磅、段后 0 磅，避免额外空行撑版
- 页边距建议：上 2.54 厘米、下 2.54 厘米、左 2.8 厘米、右 2.6 厘米
- 段落继续保持短段落阅读感，单段尽量控制在 2—3 行，避免整页大段压下去
- 不要出现空格异常、乱码、广告、外链

### 内容禁忌
- 不能涉政、涉黄、涉暴
- 不能写灵异鬼怪过于吓人、封建迷信
- 不能抹黑现实人物、职业

### 创作时的执行要求
写完一章后，除了检查情节与文风，还要额外检查：
1. 标题是否符合统一格式
2. 字数是否达到最低要求
3. 段落是否过大
4. 是否存在违规或不适合平台的内容
