# 技能索引清单

这份清单用于快速判断：
- 当前写作问题属于哪一类
- 应该调用哪个 skill
- 多个 skill 之间的先后顺序是什么

---

## 一、总控skill

### 1. 小说写作总控skill
**用途：**
用于统一调度全部小说写作 skill，适合开书、写正文、修章节、统一文风、排查人物串味、对话失真、关系没层次等综合型任务。创作时用它先定章节骨架，修稿时用它先判断该从哪一层回拉。

**适用场景：**
- “帮我按完整工作流写这章”
- “这段要整体重写”
- “帮我统一这一章的文风、人物和对白”
- “我不知道该先修哪里”

**优先级：**
当问题比较综合，优先先看它。

---

## 二、基础skill

### 2. 正文语言风格
**主要解决：**
- 提纲扩写腔
- 剧情摘要腔
- 流水账
- 文风不统一
- 句子太工整、太像文案
- “不是……却是……”这类总结型金句写顺手
- 章节读起来不像小说

**什么时候用：**
- 写正文前先定基线
- 写完后统一收束
- 修“像大纲”的章节时优先使用
- 发现旁白老在替人物总结主题时优先使用

**常见搭配：**
- 搭配场景描写
- 搭配情绪动作表达
- 最后兜底统一全章

---

### 新增：去AI味修订
**主要解决：**
- AI 腔
- 句子太工整、太会提炼主题
- “不是……而是……”这类先否后明句
- 作者代言式旁白
- 情绪、关系、成长被直接说穿
- 章节像修辞成品，不像活人当场反应

**什么时候用：**
- 章节结构已经成立，但读起来像 AI 生成
- 最后一轮想专门拆“工整句”“主题句”“解释句”时
- 明明能读，但总觉得“太顺、太圆、太会说”时
- 不想大改剧情，只想把生成味压下去时

**常见搭配：**
- 搭配正文语言风格
- 搭配情绪动作表达
- 搭配人物关系对话
- 终轮可再接章节验收与连续性校验

---

### 3. 场景描写
**主要解决：**
- 场景像背景板
- 描写像清单
- 没有气氛
- 空间不施压、不安抚、不推进

**什么时候用：**
- 开新场景时
- 写房间、院落、街道、山路、厨房、市场时
- 章节没有画面感时

**常见搭配：**
- 搭配正文语言风格
- 搭配情绪动作表达
- 感情戏时可搭配人物关系对话

---

### 4. 情绪动作表达
**主要解决：**
- “她很难过”“他很愤怒”这类直白情绪标签过多
- 情绪全靠作者解释
- 动作堆积却不精准
- 情绪表达发平

**什么时候用：**
- 修人物情绪段落时
- 修暧昧、争执、委屈、隐忍、崩溃时
- 需要少解释、多呈现时

**常见搭配：**
- 搭配正文语言风格
- 搭配人物关系对话
- 搭配人物专属动作签名

---

### 5. 人物专属动作签名
**主要解决：**
- 人物动作串味
- 所有人反应都一个模子
- 角色身体语言没有区分度

**什么时候用：**
- 建主要角色时
- 修“主角和男主像一个人”时
- 长篇连载中保持角色稳定性时

**常见搭配：**
- 搭配人物专属台词签名
- 搭配情绪动作表达
- 重要人物出场前优先校准

---

### 6. 人物专属台词签名
**主要解决：**
- 所有人说话都像作者
- 对白没有辨识度
- 角色台词都太会说
- 对话像信息搬运

**什么时候用：**
- 设计主要人物说话方式时
- 修大量对白章节时
- 修“谁都一个口气”时

**常见搭配：**
- 搭配人物关系对话
- 搭配人物专属动作签名
- 搭配正文语言风格

---

### 7. 人物关系对话
**主要解决：**
- 同一个角色对谁都一个语气
- 关系变化写不出来
- 感情线不动人
- 对话只有信息，没有关系张力

**什么时候用：**
- 修亲情、爱情、敌对、合作、上下级对话时
- 设计男女主互动时
- 修“对白很平”时

**常见搭配：**
- 搭配人物专属台词签名
- 搭配情绪动作表达
- 感情戏可搭配场景描写

---

### 8. 章节验收与连续性校验
**主要解决：**
- 章节是否符合当前 SOP
- 章节是否真的按大纲推进
- 是否出现剧情回退、信息复述、连续性混乱
- 是否因为补字导致重复增多、推进变少

**什么时候用：**
- 每章写完后准备进入下一章时
- 每章修订完成后准备交付时
- 批量补字或重写后做终轮复核时
- 觉得“这一章单看还行，但放进全书可能会乱”时

**常见搭配：**
- 搭配小说写作总控skill
- 搭配章节创作工作流模板
- 搭配章节修订工作流模板

## 三、常见问题 -> 推荐调用顺序

### 问题1：这段像流水账
推荐顺序：
1. 正文语言风格
2. 场景描写
3. 情绪动作表达

### 问题2：人物不像活人
推荐顺序：
1. 人物专属动作签名
2. 人物专属台词签名
3. 人物关系对话

### 问题3：句子太工整，像AI在提炼主题
推荐顺序：
1. 去AI味修订
2. 正文语言风格
3. 情绪动作表达
4. 人物关系对话
配套 workflow：
`SOP资料/workflows/去AI味修订工作流模板.md`

### 问题3A：剧情没问题，但读起来像AI写的
推荐顺序：
1. 去AI味修订
2. 正文语言风格
3. 情绪动作表达
4. 人物专属台词签名
配套 workflow：
`SOP资料/workflows/去AI味修订工作流模板.md`

### 问题4：对白都一个味儿
推荐顺序：
1. 人物专属台词签名
2. 人物关系对话
3. 情绪动作表达

### 问题5：感情戏不动人
推荐顺序：
1. 人物关系对话
2. 情绪动作表达
3. 场景描写
4. 正文语言风格

### 问题6：章节整体发散
推荐顺序：
1. 小说写作总控skill
2. 如果是从零写章，先看章节创作工作流模板里的“挂事 -> 拧紧 -> 翻面 -> 留门”
3. 如果是修旧稿，先看章节修订工作流模板里的“找章心 -> 砍空段 -> 补火点 -> 重挂尾”
4. 正文语言风格
5. 按问题补调其余skill

### 问题7：想检查这一章是否符合SOP、是否推进大纲
推荐顺序：
1. 章节验收与连续性校验
2. 小说写作总控skill
3. 按验收结果回调对应写作skill

### 问题8：长篇连载越写越重，想减少上下文消耗
推荐顺序：
1. 低Token连载工作流模板
2. 小说写作总控skill
3. 章节验收与连续性校验

## 四、最稳的默认工作流

如果不确定先用哪个，默认这样：

1. 长篇连载中段默认先看 **低Token连载工作流模板**
2. 再看 **小说写作总控skill**
3. 写新章时，先用 **章节创作工作流模板** 定“挂事 -> 拧紧 -> 翻面 -> 留门”
4. 修旧稿时，先用 **章节修订工作流模板** 走“找章心 -> 砍空段 -> 补火点 -> 重挂尾”
5. 如果本章结构已立，但明显有 AI 味，再接 **去AI味修订** 和 `SOP资料/workflows/去AI味修订工作流模板.md`
6. 再用 **正文语言风格** 定基线，并顺手扫一遍“不是……却是……”这类工整总结句
7. 根据问题类型，从下面挑主skill：
   - 场景问题 -> 场景描写
   - 情绪问题 -> 情绪动作表达
   - 动作串味 -> 人物专属动作签名
   - 台词串味 -> 人物专属台词签名
   - 关系发平 -> 人物关系对话
8. 最后回到 **正文语言风格** 做统一收束
9. 章节完成后，用 **章节验收与连续性校验** 做终轮验收

## 五、一句话速查版

### 补充硬规则
- 任何 skill 的调用结果都不能为了凑字数而凑字数。
- 禁止通过重复段落、重复表意、同义反复硬拉字数；一旦发现，优先删改而不是保留。

### 两个最常用的章法提醒
- 从零写章先记：`挂事 -> 拧紧 -> 翻面 -> 留门`
- 修既有稿先记：`找章心 -> 砍空段 -> 补火点 -> 重挂尾`

- **不知道先修哪儿** -> 小说写作总控skill
- **像流水账** -> 正文语言风格
- **没画面** -> 场景描写
- **情绪太直白** -> 情绪动作表达
- **人物动作都一样** -> 人物专属动作签名
- **人物台词都一样** -> 人物专属台词签名
- **关系写不出来** -> 人物关系对话
- **想验收这一章能不能过、有没有写乱** -> 章节验收与连续性校验
