# 章节修订工作流模板

这份模板用于处理中文网文与长篇小说的章节修订。

**文档交付要求：**章节正文正式落地时，默认使用可直接被 Word 打开的真实 Word 文档，优先 `.docx`；不要用 HTML 伪装 `.doc` 充当正式稿。
目标不是把章节修得“更花”，而是把章节修得：
- 不为凑字数硬塞重复内容
- 不用重复段落、重复表意、同义反复硬拉字数
- 更像小说
- 更适合连载
- 更有画面
- 更有人物区分
- 更有继续阅读的牵引力

可与以下 skill 配套使用：
- 小说写作总控skill
- 去AI味修订
- 正文语言风格
- 场景描写
- 情绪动作表达
- 人物专属动作签名
- 人物专属台词签名
- 人物关系对话

---

## 一、章节修订总原则

修稿顺序永远是：

1. **先修结构**
2. **再修场景与人物**
3. **最后修句子与节奏**
4. **如果主要问题是 AI 味，再按“先删解释 -> 再看节奏 -> 再补细节 -> 最后修句子”走专项拆味**

不要一上来就雕句子。
如果一章本身：
- 没推进
- 没画面
- 没关系变化
- 没情绪落点

那句子修得再漂亮，也只是“好看的空稿”。

如果这一章章心已成立，但开头概括、过渡句、心理句、对话高潮、段尾收束明显带生成味，优先接入：
- `SOP资料/skills/去AI味修订/SKILL.md`
- `SOP资料/workflows/去AI味修订工作流模板.md`

## 二、章节修订四轮法

# 第一轮：结构修订

## 目标
先确认这章“是不是成立”。

## 要检查的问题
- 这一章的核心任务是什么？
- 这一章推进了什么？
- 这一章有没有明确的起、承、转、落？
- 这一章结束时，人物处境有没有变化？
- 章尾有没有继续阅读的牵引力？

## 常见问题
### 1. 只有日常，没有推进
表现：写了很多生活内容，但读完像没发生事。

修法：
- 给这一章加一个明确问题
- 给这一章加一个结果
- 给章尾加一个未尽的压力或期待

### 2. 节奏平均，没有轻重
表现：每段都一样长、一样平。

修法：
- 找出真正重要的场面，加重
- 过渡段压短
- 让关键冲突、关键发现、关键情绪点更突出

### 3. 章尾没钩子
表现：像随手停住。

修法：
章尾至少留下一个：
- 决定
- 隐忧
- 新问题
- 人物关系变化
- 下一步行动预告

---

# 第二轮：场景修订

## 目标
让章节从“事件说明”变成“发生在具体空间里的小说”。

## 要检查的问题
- 每个重要段落是不是落在具体场景中？
- 场景是不是对人物施加了影响？
- 有没有至少1到2个可记忆的画面？
- 场景是不是推动了下一步行动？

## 常见问题
### 1. 场景像背景板
修法：
补上：
- 一个视觉锚点
- 一个触感/声音细节
- 一个人物与环境的接触动作
- 一个由环境带出的判断

### 2. 描写像清单
修法：
删掉无功能细节，只留：
- 能传达情绪的
- 能传达贫富/压力的
- 能影响行动的

### 3. 有画面但没作用
修法：
让场景参与剧情，而不是只负责好看。

---

# 第三轮：人物修订

## 目标
确保这一章里的人物：
- 活
- 可分
- 不串味
- 对话有关系张力

这一轮建议按以下顺序修：
1. 人物专属动作签名
2. 人物专属台词签名
3. 人物关系对话
4. 情绪动作表达

## 要检查的问题
- 主要人物动作是否彼此不同？
- 主要人物台词是否彼此不同？
- 同一个角色面对不同人时，说话方式是否变化？
- 情绪是否通过动作、停顿、物件落地？

## 常见问题
### 1. 人物动作串味
修法：
- 给每个主要角色保留1到2个核心动作特征
- 删掉“所有人都皱眉/抿唇/冷笑”这种统一反应

### 2. 台词全像作者
修法：
- 缩短过于完整、过于正确的句子
- 让每个人只说“他会说的话”
- 允许有人说不全，有人不解释，有人只说实事

### 3. 关系没层次
修法：
- 检查称呼、打断权、语气、停顿
- 增加潜台词
- 让同一句话因对象不同而变化

### 4. 情绪太直白
修法：
把：
- 她很难过
- 他很愤怒
- 她很紧张

改成：
- 动作
- 呼吸
- 物件处理方式
- 说话节奏变化
- 沉默

---

# 第四轮：语言与节奏修订

## 目标
统一全文气质，让它真正成为“可发的章节”。

这一轮最后再调用：
- 正文语言风格

## 要检查的问题
- 有没有提纲扩写腔？
- 有没有重复解释？
- 有没有太多同义反复？
- 句子长短是否有变化？
- 段落呼吸是否自然？
- 章尾是否有力？

## 常见问题
### 1. 情绪解释重复
修法：
动作和台词已经说明的，不再重复翻译。

### 2. 句子都一个长度
修法：
- 冲突句短一点
- 氛围句舒一点
- 转折处收紧

### 3. 过度修辞
修法：
删掉不服务剧情和气氛的漂亮句。

### 4. 章尾无劲
修法：
把章尾收在：
- 决定
- 一句有余味的话
- 一次关系变化
- 一个即将到来的问题

---

## 三、不同类型章节的修订重点

### 1. 开篇章
优先修：
- 钩子
- 冲突
- 主角立住
- 章尾牵引力

### 2. 过渡章
优先修：
- 是否真的承担承上启下功能
- 是否有小结果，而不是空转
- 是否埋下新动势

### 3. 感情戏章节
优先修：
- 关系温度
- 潜台词
- 情绪动作
- 场景配合

### 4. 经营/做事章节
优先修：
- 信息是否太干
- 是否有生活感
- 是否有人物互动
- 是否有明确收获或风险

### 5. 冲突章节
优先修：
- 冲突是否拉得起来
- 角色说话是否符合身份
- 是否有人物真实情绪，而不是只有情节功能

---

## 四、最实用的章节自检清单

修完一章后，最后问自己：

1. 这一章能不能一句话说清“发生了什么”？
2. 这一章有没有至少一个能记住的画面？
3. 这一章有没有太会总结、太会解释、太会说、太知道主题是什么？
4. 有没有哪一段删掉心理句就直接塌掉？

如果后两条任意一条答案是“有”，不要只润色，回到 `去AI味修订工作流模板.md` 重新拆。
3. 主角在这一章里有没有体现出独特性？
4. 对话有没有关系温度，而不是纯信息交换？
5. 有没有至少一个情绪点是靠动作落地，而不是作者解释？
6. 有没有删掉提纲扩写腔和重复解释？
7. 章尾能不能让人想看下一章？

如果这 7 条里有 3 条以上答不上来，这章还不能算修完。

## 五、推荐调用顺序速查版

### 情况A：这一章整体很烂，不知道从哪修
调用顺序：
1. 小说写作总控skill
2. 正文语言风格
3. 场景描写
4. 人物相关skill
5. 回到正文语言风格统一收束

### 情况B：这章像流水账
调用顺序：
1. 正文语言风格
2. 场景描写
3. 情绪动作表达

### 情况C：这章人物都像一个人
调用顺序：
1. 人物专属动作签名
2. 人物专属台词签名
3. 人物关系对话
4. 情绪动作表达

### 情况D：这章感情线发平
调用顺序：
1. 人物关系对话
2. 情绪动作表达
3. 场景描写
4. 正文语言风格

## 六、一句话版修稿原则

> 先修“这章有没有成立”，再修“这章像不像小说”，最后才修“这章写得漂不漂亮”。

这份模板适合长期复用。每次修章时，先按四轮走一遍，再根据具体问题调用对应 skill。

如果这一章准备正式交付或准备进入下一章，最后补跑一次“章节验收与连续性校验”。

## 七、修订时额外检查的硬性要求

### 标题格式
统一为：`第X章 XXXXX`

### 字数要求
- 每章目标 3200—3800 字
- 任何一章最低不低于 3200 字

### 排版要求
- 正式交付统一使用真实 `.docx` Word 文档
- 章节标题单独成行，统一为：`第X章 XXXXX`
- 章节标题使用黑体三号，居中排版
- 正文使用宋体小四，首行缩进 2 字符
- 行距固定 29 磅（可接受 28—30 磅的接近值）
- 段前 0 磅、段后 0 磅，避免额外空行撑版
- 页边距建议：上 2.54 厘米、下 2.54 厘米、左 2.8 厘米、右 2.6 厘米
- 段落继续保持短段落阅读感，单段尽量控制在 2—3 行，避免整页大段压下去
- 不要出现空格异常、乱码、广告、外链

### 内容禁忌
- 不涉政、涉黄、涉暴
- 不写过于吓人的灵异鬼怪和封建迷信
- 不抹黑现实人物、现实职业

修稿完成前，必须把这部分也过一遍。
