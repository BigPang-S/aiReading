# 章节验收记录

## 使用规则

- 每章初稿完成后，先跑一次自动验收。
- 每章修订完成后，准备进入下一章前，再跑一次终轮验收。
- 每次验收结果都追加写入本文件，不覆盖旧记录。
- 若验收结论为“不通过”，默认不进入下一章。
- 若验收结论为“警告”，可以继续，但必须记录风险点。

## 自动验收命令

在项目根目录运行：

```bash
python3 scripts/run_chapter_acceptance.py --chapter 小说正文/001_章节名.docx
```

如果当前章还不是 `.docx`，也可传入 `.md` 或 `.txt`。

## 自动验收默认读取

- `项目规则.md`
- `小说框架/03_总目录.md`
- `小说正文/`
- 当前传入章节文件

## 自动追加记录内容

脚本运行后，会自动把以下内容追加到本文件：

- 验收时间
- 文件
- 章节标题
- 验收结论
- 正文字数
- 大纲匹配结果
- 阻塞问题
- 风险警告
- 通过项摘要
- 下一步动作建议

## 手动补充要求

脚本只能解决硬规则与高相似重复检查。
每次自动验收后，仍应人工补一句：

- 这章推进了什么
- 是否真的把故事往前推了一步
- 是否存在脚本没法判断的关系回退、人物失真、时间线错位
