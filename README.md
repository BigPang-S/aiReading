# aiReading

这个仓库现在只做一件事：

- 作为小说 SOP 工具和新书启动模板的根入口

根目录不再堆项目快照。
真正要用的内容，只看：

- `新书模板/`

## 现在怎么用

如果你要开下一本书，直接按这个顺序走：

1. 进入 `新书模板/`
2. 先看 `新书模板/README.md`
3. 把你的原始大纲或脑洞写进 `新书模板/开书输入.md`
4. 再看 `新书模板/SOP资料/workflows/开书初始化工作流.md`
5. 直接用 `新书模板/SOP资料/说明文档/Codex开书初始化提示模板.md` 让 Codex 完成初始化
6. 初始化完成后，再进入日常连载循环

## 新书模板里最重要的入口

- `新书模板/README.md`
- `新书模板/下一本小说直用工作流.md`
- `新书模板/开书输入.md`
- `新书模板/当前有效规则卡.md`
- `新书模板/SOP资料/workflows/开书初始化工作流.md`
- `新书模板/SOP资料/workflows/低Token连载工作流模板.md`

## 根目录保持什么状态

根目录默认只保留：

- `.git/`
- `README.md`
- `.gitignore`
- `新书模板/`

也就是说：

- 根目录是入口层
- `新书模板/` 是真正执行层

如果后面再有临时资料、旧快照、试验目录，默认不要继续堆在根目录。
